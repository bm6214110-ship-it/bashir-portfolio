# bashir-portfolio

Portfolio website for Bashir bin Mohammed — Astro + React + Tailwind, bilingual AR/EN, admin dashboard scaffold.

## Stack
- Astro
- React islands
- Tailwind CSS
- Supabase-ready
- Cloudflare Pages-ready

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
